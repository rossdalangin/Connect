# Step-by-Step SaaS Build Plan

## Phase 1: MVP (Minimum Viable Product)
**Goal:** Establish core routing and basic profile management.
1.  **Foundation:** Register `saas_profile` and `saas_link` Custom Post Types.
2.  **Routing:** Implement the vanity URL rewrite rules (`domain.com/username`).
3.  **Profile Theme:** Create a minimalist mobile-first template with basic CSS variables for colors.
4.  **Basic Dashboard:** Build a simple frontend form to update profile headline and bio.
5.  **Link Engine:** Enable users to add/delete simple external links.

## Phase 2: Scale (Enhancement & Monetization)
**Goal:** Add professional features and recurring revenue.
1.  **Modular Blocks:** Implement complex types (Video, FAQ, Testimonials, Pricing).
2.  **Visual Dashboard:** Add the Real-time Mobile Preview using PostMessage API.
3.  **Payment Gateway:** Integrate Stripe/PayPal stubs and license validation logic.
4.  **Pro Gating:** Badges, whitelabeling, and restricted block types.
5.  **Analytics:** Set up the custom SQL table for high-performance view/click tracking.
6.  **Template Engine:** Create niche-specific presets (Coach, Realtor, etc.).

## Phase 3: Automation (Optimization & Ecosystem)
**Goal:** Deepen the value proposition and automate user growth.
1.  **Lead Generation:** Build the dynamic form engine and database storage.
2.  **Lead CRM:** Add status tracking, search, and CSV export to the user dashboard.
3.  **Automation:** Implement external webhook triggers (Zapier/Make) and lead magnet delivery.
4.  **Growth Tools:** Automated QR code generation and NFC encoding guides.
5.  **SEO Suite:** Custom meta tags, favicon uploads, and real-time search mockup preview.
6.  **Global UI:** Add "Verified ✅" badges and profile-level password protection.
